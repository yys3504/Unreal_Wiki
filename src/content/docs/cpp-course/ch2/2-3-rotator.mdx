**Rotator**는 오브젝트가 현재 어느 방향을 향하는지 **각도(Degree)** 로 표현하는 타입입니다. 이번
페이지는 핵심을 빠르게 잡을 수 있도록 **축 기준과 구성 요소**에 집중합니다.

## Rotator의 정의

**`FRotator`** 는 회전 상태를 Pitch·Yaw·Roll 세 각도로 나타내는 구조체입니다.

```cpp
FRotator NewRotation(0.f, 90.f, 0.f);
Actor->SetActorRotation(NewRotation);
```

:::caution[생성자 인자 순서 주의]
`FRotator`의 생성자 순서는 **`FRotator(Pitch, Yaw, Roll)`** 입니다. Pitch가 가장 먼저라는 점을
헷갈리기 쉬우니 주의하세요.
:::

  - **Y**: Right
  - **Z**: Up
