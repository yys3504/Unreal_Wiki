이 코스는 **하나의 작은 게임을 한 단계씩 만들어 가며** 언리얼 C++의 핵심 시스템을 익히는
순차 코스입니다. 각 모듈은 _플레이 가능한 결과물_ 하나와 _개념 묶음_ 하나를 더합니다.

## 만들 게임 — Arena Survivor

탑다운(또는 오버숄더) **웨이브 생존 슈터**입니다.

- WASD로 이동하고 마우스로 조준·발사한다.
- 아레나 가장자리에서 적이 웨이브로 스폰되어 플레이어를 추격한다.
- 투사체로 적을 처치하면 점수를 얻고, 체력이 0이 되면 게임 오버.
- 마지막 웨이브를 클리어하면 승리.

> 네트워크나 대용량 에셋 없이, 언리얼 C++의 핵심(액터·컴포넌트·입력·충돌·델리게이트·
> GameMode·UMG·데이터/세이브)을 **자연스러운 순서로 전부** 요구하는 최소 게임입니다.

## 환경 (요약)

- **엔진**: Unreal Engine 5.6 — C++ **3인칭 템플릿**으로 시작
- **IDE**: JetBrains Rider 권장 (또는 Visual Studio 2022 + "C++ 게임 개발" 워크로드)
- **입력**: Enhanced Input (UE5 기본)
