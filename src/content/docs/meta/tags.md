태그는 섹션을 가로지르는 **발견 레이어**입니다. 난립하면 없느니만 못하므로 **닫힌 어휘**로
관리합니다. 새 태그가 필요하면 먼저 이 문서에 추가하세요.

## 난이도

| 태그 | 의미 |
| --- | --- |
| `beginner` | 입문자 대상 |
| `intermediate` | 중급 |
| `advanced` | 고급 |

## 언어 / 패러다임

| 태그 | 의미 |
| --- | --- |
| `cpp` | C++ 중심 |
| `blueprint` | 블루프린트 중심 |

## 서브시스템

| 태그 | 의미 |
| --- | --- |
| `actor` | 액터/컴포넌트 |
| `input` | 입력(Enhanced Input) |
| `gas` | Gameplay Ability System |
| `ai` | AI / Behavior Tree |
| `umg` | UI / UMG |
| `physics` | 물리/충돌 |
| `replication` | 네트워킹/리플리케이션 |
| `rendering` | 렌더링/그래픽스 |
| `data` | 데이터 주도(DataAsset/DataTable)·세이브 |
| `tools` | 에디터 툴/워크플로우 |

## 종류

| 태그 | 의미 |
| --- | --- |
| `reference` | 개념 설명 |
| `recipe` | 복붙용 짧은 코드 |
| `troubleshooting` | 문제 해결 |
| `crash` | 크래시 |
| `compile-error` | 컴파일/링크 에러 |
| `meta` | 위키 자체에 대한 문서 |
