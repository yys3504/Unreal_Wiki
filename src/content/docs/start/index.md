이 위키는 **언리얼 엔진**에 대한 한국어 지식 베이스입니다. 링크만 있으면 누구나 볼 수 있고,
모든 문서는 마크다운 + Git으로 관리됩니다.

## 이 위키는 누구를 위한 것인가

- 일반적인 C++(클래스·포인터·상속·헤더/소스)은 알지만 **언리얼 C++은 처음**인 사람
- 작은 게임을 직접 만들며 엔진의 핵심 시스템을 손에 익히고 싶은 사람

## 어떻게 구성되어 있나

번호가 붙은 섹션으로 나뉘며, 번호는 **고정된 위치**를, 태그는 **가로지르는 발견 경로**를 뜻합니다.

| 섹션 | 성격 | 설명 |
| --- | --- | --- |
| **10 · C++ 코스** | 순차 코스 | 하나의 게임을 단계별로 만든다. 이전/다음으로 이어 읽는다. |
| **20~80 · 레퍼런스** | 비순차 | "X는 어떻게 동작하나" / 문제 해결 / 코드 레시피. 필요할 때 찾아본다. |
| **90 · 메타** | 운영 | 스타일 가이드·템플릿·태그·버전 정책 등 위키 자체에 대한 문서. |

:::tip[읽는 순서]
처음이라면 **10 · C++ 코스**를 1번 모듈부터 순서대로 따라가세요. 특정 개념만 찾는다면
상단 검색이나 태그를 이용하면 됩니다. 모든 페이지는 링크로 공유되어 **단독으로도 이해되도록**
작성됩니다.
:::

## 코드 표기 규칙 (요약)

- C++ 블록은 항상 언어와 **파일명**을 함께 표기합니다. 헤더(`.h`)를 먼저, 구현(`.cpp`)을 나중에.
- 새 파일을 처음 소개할 때는 **전체**를, 이후 수정할 때는 **바뀐 부분만** 줄 강조로 보여줍니다.
- 모든 코드 블록에는 **복사 버튼**이 있습니다.
- API 식별자·클래스명·매크로·메뉴 경로는 **원문 영어** 그대로 둡니다(예: `UPROPERTY`, `Edit > Project Settings`).

자세한 작성 규칙은 [90 · 메타](/meta/)의 스타일 가이드를 참고하세요.

:::note[작성 예정]
환경 설정(UE 버전·IDE·빌드)과 코드 규칙 상세 페이지는 곧 추가됩니다.
:::
